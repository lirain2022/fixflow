# RE:FIX 前導網站

在 `frontend` 執行 `npm ci`，再執行 `npm run dev:system`。後端仍使用專案根目錄的 `start-backend.cmd`。

- 首頁：http://127.0.0.1:5175/
- 會員中心：http://127.0.0.1:5175/member.html
- 管理員工作空間：http://127.0.0.1:5175/system.html?portal=admin
- 原本獨立的展示頁保留於 `/demo.html`，不作為正式報修入口。

首頁的服務選單與服務卡片會開啟 `/repair.html` 並預選分類；維修流程介紹位於 `/process.html`。尚未登入者先登入或註冊，再填寫報修資料與選填零件需求。首頁報修與會員新增報修共用同一張表單，按一次「送出報修」一起建立工單與零件需求。填寫時不顯示重複的會員摘要、分頁及新增報修按鈕。網路對應「網路」、3C 與智慧設備對應「設備」、家電先選「其他」，使用者可在表單中改選空調等分類；已有草稿時優先接續草稿分類。

報修與零件欄位以同來源 `sessionStorage` 暫存在同一分頁一小時，不放入網址。登入過期仍可重新登入後接續。送出成功、確認取消報修或手動登出後清除暫存。網路中斷而結果不明時，先查看「我的報修」避免重複建立；確認未建立後可回表單恢復編輯。管理員工作區的工單草稿仍依原本機制保存。

「查詢維修進度」與費用明細入口開啟 `/member.html?next=tickets`，會員登入後只會列出本人報修。首頁費用說明對應人工費與零件費，不提供固定報價；常見問題使用原生可展開項目，支援鍵盤操作。管理員登入仍使用獨立入口 `/system.html?portal=admin`。

原型的「診斷」展示提示已替換為實際報修流程；這個入口不會自動判斷故障或產生報價。

3D 場景延遲載入，支援拖曳旋轉、點擊光波與暫停；離開可視範圍或背景分頁時停止場景。不依賴原型的遠端 HDR 檔。無法顯示 WebGL 或使用者開啟減少動態效果時顯示靜態替代畫面。Google Fonts 無法載入時使用系統字型。

`npm run build:system` 同時產生首頁與系統頁到 `dist-system`；Docker/Nginx 以首頁為預設，保留 `/api/` 代理至既有後端。開發環境也使用同來源 `/api`，無須另外開前導網站伺服器。
