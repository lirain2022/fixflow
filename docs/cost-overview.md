# 維修費用總覽

從側邊欄「費用總覽」進入，預設顯示本月至今，可切換全部期間。

- 已登錄費用：每筆正式維修紀錄的人工費、零件費與合計。草稿不列入；免費維修的 0 元仍是有效紀錄。
- 未登錄費用：已完成但沒有維修紀錄、或歷史維修紀錄尚未填費用的工單。0 元不會誤列為未填。開啟工單後，可在維修紀錄按「補登費用」。
- 未連結設備：尚未綁定設備且未取消的工單。結案後仍能從工單詳細資訊補連結設備，已登錄費用不會消失。

篩選包含日期、設備名稱／編號及目前負責人。已登錄費用按維修完成時間（台北時區）篩選；待補資料清單按工單建立時間篩選。舊紀錄若沒有完成時間，以該筆紀錄建立時間計。人員是工單目前負責人，不代表當時維修人員。

摘要包含所有符合篩選的資料，不只當頁。每頁 10 筆，可直接點工單開啟詳細資訊。CSV 採相同篩選與權限，每次最多 5000 筆，超過時需縮小範圍，不會靜默截斷。

一般帳號可見自己建立或目前指派給自己的工單；管理員可見全部。報表與人員選單都遵守此範圍。

本次無資料庫結構變更。更新後需要重新啟動後端，再重新整理前端。

手機版費用明細以卡片呈現，金額與操作按鈕不必左右滑動即可看到。空清單可按「清除篩選」顯示全部期間，並保留目前的費用分類。金額統一標示 NT$。

## 補登與更正維修費用

待驗收或已結案工單，在「維修紀錄與費用」按「補登費用」或「更正費用」，填寫原因、工時、人工費與零件後儲存。系統保留更正前後工時與金額、原因、操作人及時間；原維修說明、原處理人、完工時間、結案狀態與時間保持不變。費用更正紀錄可展開查看。

「設為免費維修」會將人工費和零件單價改為 0，保留零件名稱與使用數量，仍需填寫原因並按儲存。尚未填寫費用和明確登錄 0 元是不同狀態。

更正會更新原維修紀錄的金額，因此工單、設備履歷與費用總覽不會重複累加。費用總覽依原維修完成日期歸屬期間，所以更正過往費用會反映在過往期間。若舊工單完全沒有維修紀錄，補登會建立一筆費用紀錄，採用原完工時間，缺少時使用結案時間或工單建立時間。

結案前顯示設備連結與費用完整性提醒。提醒不強制阻擋結案；未連結設備可到設備管理的「未連結工單與費用」補連結。

只有原本可存取工單的帳號才能更正；已取消或尚未完成維修的工單不能使用此入口。版本衝突時本次輸入會保留，但需重新開啟工單確認最新金額後再送出。
