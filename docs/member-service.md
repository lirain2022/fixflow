# RE:FIX 會員中心

一般會員從首頁右上角「會員登入」進入。登入後回首頁，右上角會出現姓名及「會員中心」。從「查詢維修進度」或「線上報修」登入，會接續原來的目的地。

## 會員可以做什麼

- 我的報修：只列出本人建立的工單，可依狀態或關鍵字查詢。上方摘要顯示處理中、待驗收、已結案數量，點選可直接篩選。處理中涵蓋待派工、已派工及維修中。列表也可使用狀態下拉選單，或按「清除篩選」恢復全部。
- 詳細資料：查看處理人員、進度、正式維修紀錄、費用、照片與留言。未登錄費用不代表免費；部分未登錄會另行提示。
- 待派工／已派工時可以取消；待驗收時可以確認驗收，或填寫原因退回維修。
- 零件需求：在尚未進入驗收的工單填寫名稱、數量、用途／規格與選填參考連結。待確認需求可以撤回。
- 通知：查看本人報修更新及零件需求回覆，點擊通知開啟對應工單。
- 帳號設定：修改密碼後重新登入，舊登入狀態失效。

需求只是提出希望更換或加裝的零件，不代表購買、報價或付款，也不會自動加到維修費用。實際費用仍由管理員在維修紀錄登錄。

## 管理員操作

使用首頁「管理員登入」進入原管理工作區。打開工單詳細資訊，在「會員零件需求」回覆規格或相容性，選「已回覆」或「不適用」。會員會收到通知。派工、維修紀錄、設備管理、費用總覽仍在同一套管理工作區。

本次不變更既有帳號角色或密碼。一般會員與舊技師帳號現在只能從會員端看本人報修，內部管理 API 需要 ADMIN；這是後端限制，修改網址或使用舊登入 token 都不能繞過。

## 入口與資料

- 首頁：/
- 會員登入：/member.html?screen=login
- 會員中心：/member.html
- 接續報修：/member.html?next=report
- 查詢進度：/member.html?next=tickets
- 管理員：/system.html?portal=admin

舊 /system.html 自動轉至會員登入；舊 action=new 與 view=tickets 仍會接續正確目的地。會員與管理員使用不同的 sessionStorage key。報修草稿只在目前分頁暫存一小時，手動登出會清除，登入過期則保留以便接續。

資料遷移 V6 新增 ff_part_requests 以及通知的 part_request_id，不刪除工單、使用者、設備或維修費用。更新前停止後端並備份資料庫。此版本驗證使用隔離 H2；正式 PostgreSQL 部署仍需在該環境驗證遷移。

## 限制與驗證

數量為 1–99；名稱最多 120 字；用途最多 2000 字；參考連結最多 1000 字，僅接受無帳密的 HTTP／HTTPS 網址，伺服器不抓取外連。提交結果不明時先重新載入確認，避免重複送出。工單已進入驗收時拒絕新需求並保留目前輸入。

看完工單返回列表或切換會員分頁，會保留搜尋條件與頁碼；登出清除。點摘要卡片會清除搜尋並從第一頁開始，避免數量與結果不符。若狀態變動使最後一頁變空，會自動回到可用頁面；摘要讀取失敗時可單獨重試。正式報價同意、付款、商城與保固不屬於本次版本。
